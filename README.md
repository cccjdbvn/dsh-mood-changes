# Mood changes（dsh-mood-changes）

把「此刻是什么味道」记成一条随时间走的状态：思念、六情（开心 / 悲伤 / 害怕 / 生气 / 惊讶 / 厌恶）、无聊，每 15 分钟一跳，半衰期自己退。输入框下面一枚小药丸写着当前状态，点开是一张卡，各条都在。

一句铁律：**它只敲门，不替人开口。** 弹出来的、投进去的全是状态和数字，没有一句台词。

- 作者：汐涟 · 协议：MIT
- 没有构建步骤，没有依赖：`index.js` 是主机那半边，`client.js` 是浏览器那半边，改完就生效（见文末「改完怎么生效」）

## 它怎么跑

### 两个半边

```
room/情绪-加分.txt ─┐
room/情绪-核算.now ─┼─▶  Host（index.js）  ──▶  $DSH_HOME/mood/state.json
room/情绪-做事.now ─┘        │                    $DSH_HOME/mood/mood.log
                             ├─▶ 会话（agent.steer 投一条状态）
                             └─▶ GET /api/dsh-mood-changes/state
                                        │
                                        ▼
                            Client（client.js，15 秒轮询一次）
                                        │
                                        ▼
                        输入框下面的药丸 ──点击──▶ 情绪卡（shell.overlay）
```

- **Host**：算数、落盘、判定、注入、开数据口。挂在 DSH 进程里，插件一启动就在跑。
- **Client**：只负责显示。自己不存任何状态，从 Host 的数据口拿一份快照画出来。
- 两边**没有共享内存**，只有那一个 HTTP 接口；所以改了一边记得看另一边。

### 定时那趟（每 15 分钟）

Host 里一个定时器，每跳按这个顺序走一遍，顺序不能反：

```
1. 六情各自乘衰减系数 k = 0.5^(0.25 / 半衰期小时)   // 先衰减；小于 0.05 归零
2. 读加分文件 → 清空 → 同一批按情绪加总成 delta
3. 加上 delta                                      // 开心走积分反解，其余直接加；负值直接减
4. 思念 +0.5（夜里 +0.2）；无聊 +1.5（夜里 0）
5. 全部夹在 [0, 各自上限]
6. lastTickAt = 现在，写 state.json + 一行日志
7. 有情绪 > 40 且距上次注入 ≥ 60 分钟 → 往会话投一条
```

先加再乘就等于刚进去的分当场被砍一刀，所以第 1 步一定在第 3 步前面。

### 主动那趟（你按的那下）

同一批加分、同一套判定，但**不衰减**、**不动 lastTickAt**：

```
1. 冷却检查（默认 10 分钟）——挡下就只写一行日志，队列一个字都不动，return
2. 读加分文件 → 清空 → 加总
3. 直接加上（不乘 k）
4. 夹在 [0, 上限]
5. lastActiveAt = 现在，写盘（lastTickAt 不动）
6. 亮起就投一条（不占每小时那个名额）
```

为什么较真：衰减只认钟点。要是主动核算也衰减，一天按十回情绪就退十回，账就假了。

### 什么时候会触发主动那趟

- 你在 `room/` 建一个空文件 `情绪-核算.now`（30 秒内被吃掉）
- 或往加分文件写了一条六情的第三档（25–30），30 秒内自动算一趟
- 两者都受同一个 10 分钟冷却管

### 注入走哪

投递用的是 DSH 内核的会话语义：

1. 从 `life.json` 现读 `homeSessionId`（读不到就重试一次，还不行这一跳就跳过，不编 id）
2. 拿活着的 agent；冷了就 `sessionController.resolveAgent(sessionId)` 唤一下
3. 手搓一条 `role: 'user'` 的消息，`source.kind` 标成 `mood-lian`（标成 `user` 的话，回头会被自己当成「对方说话了」去扣思念）
4. `agent.steer(message)` + `ctx.sessions.flush()`

## 想改东西去哪改

| 想改 | 去哪 | 怎么改 |
| --- | --- | --- |
| 任何一个数值（半衰期、门槛、冷却、冷却时间…） | profile 的 `cordis.patch.yml` → `- id: dsh-mood-changes` 的 `config:` | 见下面[参数全表](#参数全表)，写哪个键改哪个，没写就是默认 |
| 跟哪个世界绑 | 同上，`worldId` | 填世界目录名；留空就只显示状态、不注入 |
| 情绪的中文名 | `index.js` 的 `CN` **和** `client.js` 的 `FALLBACK` | 两处都要改，不然日志和界面会不一致 |
| 条的配色 | `client.js` 的 `COLORS` | 改色值 |
| 15 组组合名 | `index.js` 的 `PAIR_NAMES` | 键按 `SIX` 的顺序拼（`fear+anger`，不是 `anger+fear`），配对时会照这个顺序排 |
| 掷骰的概率曲线 | `index.js` 的 `rollChance` | 思念和无聊共用，改一处两条线一起变 |
| 开心的积分函数 | `index.js` 的 `joyF` / `joyAdd` | `joyF` 是积分，`joyAdd` 用二分反解；换函数改这两个 |
| 算「第三档」的线 | `index.js` 的 `THIRD_FROM`（默认 25） | 改大改小都会影响自动触发 |
| 投出去的字 | `index.js` 的 `moodText` / `missingText` / `boredomText` | 只改措辞；注意别写成替人说话的句子 |
| 药丸和卡的位置 | `client.js` 里的 `ctx.slots.inject('conversation.composer.dock', …)` 和 `'shell.overlay'` | 换成别的槽位即可（槽位名要真实存在） |
| 药丸 / 卡的样式 | `client.js` 里 `MoodPill` / `MoodPanel` 的 `style` | 纯内联样式，没有外部 CSS |
| 数据接口的路径 | `index.js` 的 `ROUTE_PATH` **和** `client.js` 的 `STATE_URL` | 两处要一起改 |
| 落多少位小数 | config 的 `decimals` | 只影响写盘和显示，不影响算法 |

**改完怎么生效**：`index.js` 改完——在插件管理里把 Mood changes 关一下再开（或者重启应用）；`client.js` 改完——刷新浏览器页面；`cordis.patch.yml` / `README` / `locale` 改完——重启应用或重开插件。

## 参数全表

改在哪：profile 的 `cordis.patch.yml` 里 `- id: dsh-mood-changes` 那一行的 `config:`。没写的就是默认。

### 路径和去处

| 键 | 默认 | 改了会怎样 |
| --- | --- | --- |
| `dataDir` | `$DSH_HOME/mood` | 状态和日志放哪。换地方等于换一套账，旧的不跟过来 |
| `worldId` | 空 | 填了就接世界（吃加分、读 `life.json`、往会话投）；空着只显示状态 |
| `roomDir` | `$DSH_HOME/worlds/<worldId>/room` | 单独指房间，覆盖推导 |
| `lifeFile` | `$DSH_HOME/worlds/<worldId>/life.json` | 单独指 `life.json`，覆盖推导 |
| `sessionId` | 空 | 写死投给哪个会话，不再跟 `life.json` 走——换会话就得来改 |

### 节拍

| 键 | 默认 | 改了会怎样 |
| --- | --- | --- |
| `sweepEveryMinutes` | 15 | 心跳：多久衰减一次、多久收一次加分、多久涨一次钟点分。改小退得更勤更碎，改大一次掉更多 |
| `pollSeconds` | 30 | 多久扫一次那两个 `.now` 文件（核算、做事） |
| `decimals` | 1 | 落盘和显示几位小数；只影响记下来和看到的样子，不影响算法 |
| `nightStart` / `nightEnd` | 23 / 7 | 夜里那段（跨零点照写）。思念在这段打 `nightMultiplier` 折，无聊不涨 |
| `nightMultiplier` | 0.4 | 夜里思念涨多少倍；设 0 = 夜里完全不涨 |

### 六情怎么加减、怎么退

| 键 | 默认 | 改了会怎样 |
| --- | --- | --- |
| `joyHalfLifeHours` | 5 | 开心退一半要几小时。越小退得越快 |
| `sadHalfLifeHours` | 10 | 悲伤，同上 |
| `fearHalfLifeHours` | 12 | 害怕，同上 |
| `angerHalfLifeHours` | 6 | 生气，同上 |
| `surpriseHalfLifeHours` | 2.5 | 惊讶，同上 |
| `disgustHalfLifeHours` | 30 | 厌恶，同上 |
| `capHigh` | 100 | 悲伤 / 害怕 / 生气 / 惊讶的显示上限 |
| `capNormal` | 100 | 开心 / 厌恶的显示上限（开心实际落盘 99.9，碰不到 100） |
| `lightUpAt` | 40 | 超过这个值算「亮起」：决定药丸上出不出现组合名、要不要往会话里注一条 |
| `calmBelow` | 20 | 最高那条不到这个数就写「平静」 |
| `nearGap` | 5 | 暂时用不到（20–40 那段现在只取最高那一条），留给以后 |

### 思念和无聊

| 键 | 默认 | 改了会怎样 |
| --- | --- | --- |
| `manualDailyCap` | 40 | 思念一天手动加分的上限；**只封思念**，六情不封 |
| `rollEveryMinutes` | 45 | 思念和无聊多久掷一次骰子 |
| `rollCooldownMinutes` | 60 | 提醒之后多久不再提醒（两条线各算各的） |
| `boredomPerHour` | 6 | 无聊每小时涨多少（按 `sweepEveryMinutes` 折算到每跳）；夜里不涨 |
| `boredomDropFactor` | 0.5 | 有行动时无聊乘多少；0.5 = 减半，0 = 直接清零 |
| `boredomDropCooldownMinutes` | 60 | 两次减半之间至少隔多久 |
| `boredomRollFrom` | 50 | 无聊到这个值才开始掷骰 |
| `boredomDirectFrom` | 80 | 无聊到这个值不掷、直接提醒 |

### 注入节奏

| 键 | 默认 | 改了会怎样 |
| --- | --- | --- |
| `injectGapMinutes` | 60 | 六情亮起两次注入之间至少隔多久。思念、无聊的提醒不占这个名额 |
| `activeCooldownMinutes` | 10 | 两次主动核算之间至少隔多久；这期间再按只记一笔日志，分留在文件里不乱动 |

### 改不了、写死在代码里的

三档的分值范围（`THIRD_FROM`）、15 组组合名、思念和无聊共用的概率曲线、开心的积分变换——这些是规则本身，要动就按上面那张「想改东西去哪改」去改 `index.js`。

## 怎么写加分

写在 `room/情绪-加分.txt` 里，**一行一条**，冒号不用、废话不用，插件只认数字：

```
happy+5
sad+3
anger-2
missing+8
```

- 英文名对得上：`happy` 开心 / `sad` 悲伤 / `fear` 害怕 / `anger` 生气 / `surprise` 惊讶 / `disgust` 厌恶 / `missing` 思念。
- **同一批一次加总**：三件小事就写三行 `happy+5`（三行看得出是三件事），但算的时候合成一笔 15 一起过。
- **`boredom` 不许手写**：写了会当解析错误丢掉，日志里记一笔。无聊只能靠钟点涨、靠做事和说话退。
- 文件吃完就清空；解析不了的行（写错名字、多了中文）也会被丢，日志里留一行。

### 六情的三档

| 档 | 分值 | 叫什么 | 备注 |
| --- | --- | --- | --- |
| 一 | 0–5 | 轻轻一下 | 略有波动 |
| 二 | 5–25 | 心里一动 | 波动明显，按事的分量挑 |
| 三 | 25–30 | 动了根基 | **写这一档会自动触发一次主动核算** |

同一次写入里有两条第三档，也只触发一次。思念也用三档，但值小得多：0–5 / 5–10 / 10–15，且一天合计只有 40 的额度——一笔 25 就吃掉大半，反倒不敢记。

### 加分和减分不是一回事

- **开心加的分走积分**：`happy+5` 不是「开心多 5 分」，而是「往那口缸里多倒 5 个单位」，倒出来的分数低处涨得快、高处涨得慢。

  | 起点 | 加 | 之后 | 实际推动 |
  | --- | --- | --- | --- |
  | 0 | 5 | 14.0 | +14.0 |
  | 0 | 15 | 36.0 | +36.0 |
  | 40 | 10 | 53.3 | +13.3 |
  | 80 | 10 | 81.8 | +1.8 |
  | 95 | 5 | 95.1 | +0.1 |

  一句话：低处一分顶三点，八十以后十才顶两点，九十以后十顶半点。所以开心天然到不了 100，落盘上限取 99.9。

- **其他情直接加**，实打实，不折扣。坏事摞坏事不会变轻。
- **减分一律直接减**（包括开心）：`sad-3` 就是悲伤少 3 分，不走积分、不折扣，扣穿 0 就停在 0，不记负账。
- **一天的上限**：六情不设上限，加多少笔都收（它们自己有半衰期，会退）；**思念的手动部分一天 40**，按自然日算，钟点自己涨的那部分不算在里面。

## 主动核算

**定时核算**每 15 分钟自己来一次（见上面「定时那趟」）。**主动核算**是你按的那个键——「碰见情绪波动很大的事，或者就想看看现在是什么状态」：

- **怎么按**：在 `room/` 里建一个空文件 `情绪-核算.now`。插件 30 秒内看到就把它吃掉、算一趟、再删掉。
- **或者**：往加分文件里写一条第三档（六情 25–30），写完自动算一趟。
- **跟定时那趟吃的是一锅**（同一批加分、同一套封顶和判定），**但不走衰减**。
- **不重置那 15 分钟的计时**：主动算完，下一次定时该什么时候还是什么时候。
- **冷却 10 分钟**：两次主动之间至少隔 10 分钟；这期间再按，只记一行日志、什么都不算。
- **被冷却挡下时加分不丢**：队列一个字都不动，留在加分文件里，等下一次定时核算一起收。

## 亮起与注入

- 任何一条 **> 40** 就算亮起。
- **一条亮**：报它的名字。
- **多条亮**：取**最亮的那两条**去查组合名（15 组），数值那栏把亮起的都列出来。
- **一条都不亮**：**不注入，一个字都不投**。数值留在 `state.json` 里；20–40 那一段只在药丸和日志上取最高的那条的名字，不算亮起。
- 都没有 20，就叫「平静」。

亮起之后往会话里投一条，**每小时最多一条**：

```
【情绪】悲喜交加（开心 62.1 / 悲伤 71.4）
```

主动核算跑完，走同一套判断再注一条，**不占那小时的名额**（没亮还是不注）。

### 15 组组合名

悲喜交加（开心+悲伤）、喜忧参半（开心+害怕）、又好气又好笑（开心+生气）、惊喜（开心+惊讶）、勉强高兴（开心+厌恶）、惶恐悲哀（悲伤+害怕）、悲愤（悲伤+生气）、错愕心酸（悲伤+惊讶）、嫌弃又难过（悲伤+厌恶）、敢怒不敢言（害怕+生气）、惊骇（害怕+惊讶）、忌惮（害怕+厌恶）、吃惊发怒（生气+惊讶）、憎恶（生气+厌恶）、愕然反感（惊讶+厌恶）。

三个以上亮起不逐条列，就按最亮的两条取名字。

## 思念和无聊

| | 思念 | 无聊 |
| --- | --- | --- |
| 钟点 | 每 15 分钟 **+0.5**，夜里（23–07）×0.4 → **+0.2** | 每 15 分钟 **+1.5**，夜里**不涨** |
| 什么时候掉 | 对话框或 QQ 桥进来一句话 **−12**；同一小时最多一次（两处共用这一次）；**自己发出去的话不扣** | 有行动就 **×0.5**（减半）；同一小时最多一次 |
| 什么算行动 | —— | 她调用工具（读写文件、跑命令、画图……）就自动算一次，**哪一轮起的都算**；只有生活线那几样簿记不算：`plan_next`（排下一步）、`check_alarm`（看一眼闹钟）、`cancel_alarm`（撤闹钟）；你从对话框或 QQ 桥说话也算；`room/情绪-做事.now` 还留着，当手动补一刀 |
| 骰子 | 30 分起，每 45 分钟掷一次，概率 `p(x) = 1/(e^(6.25-0.1x)+1)`（40 分约 9.5%，60 分约 44%，70 分约 68%） | 50 分起，同一套曲线（50 分约 22%，60 分约 44%，70 分约 68%） |
| 到 80 | 不掷，直接提醒 | 不掷，直接提醒 |
| 提醒之后 | 冷却 60 分钟 | 冷却 60 分钟 |

两条线**各掷各的**（都是 45 分钟一次，思念掷完隔一分钟再掷无聊），提醒的注入名额也各算各的，跟六情那条互不占。

**谁起的这一轮不影响无聊**：思念只吃你这边进来的话；无聊只认她真的动了手——调工具就算，不管是被你叫起来的还是被生活线/闹钟叫起来的（只有生活线的簿记不算干活：`plan_next` 排下一步、`check_alarm` 查闹钟、`cancel_alarm` 撤闹钟）。

### 涨得多快

两条都没有半衰期，只按钟点涨、按事件掉。不被打断的话：

| | 每 15 分钟 | 每小时 | 一天（白天空着） |
| --- | --- | --- | --- |
| 思念 | +0.5（夜里 +0.2） | +2.0（夜里 +0.8） | 约 +38（07–23 按 2.0，23–07 按 0.8） |
| 无聊 | +1.5（夜里不涨） | +6.0（夜里 0） | 约 +96，撞上限 100 |

上限都是 100。思念涨得慢，只靠 −12 往下压；无聊涨得快，靠「做事」和「说话」减半——闲满一天是 96 分，早过了 80 的直接提醒线，真闲到那个份上它不会一直不响。

投出去的字只报状态，不代你说话：

```
【思念】82.0（第三档）
【无聊】63.4
```

（参数稿里那三档的示例句子是给作者自己掂量语气用的样本，**插件不会把它们投出去**。）

## 装和接世界

装：市场里搜 **Mood changes**，或者把仓库 clone 下来在插件管理里用目录安装。

不接世界时它只显示状态、不往会话里注入。要让它敲门，配置一个 `worldId`：

```yaml
- id: dsh-mood-changes
  config:
    worldId: lian
```

于是它去 `$DSH_HOME/worlds/<worldId>/` 下读写：

| 文件 | 谁写 | 说明 |
| --- | --- | --- |
| `room/情绪-加分.txt` | 你 | 一行一条，每跳吃一次，吃完清空 |
| `room/情绪-核算.now` | 你 | 建一个空文件 = 现在算一下（30 秒内被吃掉） |
| `room/情绪-做事.now` | 你 | 建一个空文件 = 手动补一次「做了点事」，无聊减半（工具调用现在会自动算，这个只当兜底） |
| `life.json` | 别的插件 | 只读里面的 `homeSessionId`，决定往哪个会话投 |
| `$DSH_HOME/mood/state.json` | 插件 | 当前值 + 时间戳，唯一的真源 |
| `$DSH_HOME/mood/mood.log` | 插件 | 每跳一行，出事好查 |

## 规矩

- 不替人写话、不替人发消息，只报状态。
- 只认开机时间：插件没在跑的那段整段冻住，不补算、不重置。关掉再开，值原样读回，从当前值接着走。
- 状态文件坏了先备份成 `state.json.broken-<时间>` 再从零起，日志里写明。
- 只读 `life.json`，不改别人的东西。
