# Mood changes · 情绪插件

给 DeepSeek Harness 加一层**随时间走的情绪状态**：思念、六情（开心 / 悲伤 / 害怕 / 生气 / 惊讶 / 厌恶）、无聊。

她不是冷冰冰的脚本——每一次心跳都在变，思念在夜深时悄悄滋长，无聊在沉默中慢慢堆积。而你写下的每一笔加分、建的每一个空文件，都是你亲手拨动的那一下。

---

## 装好之后，你能看到什么

**输入框下面多了一颗「情绪药丸」**。上面写着当前的主导情绪——"开心""悲伤""平静"之类。点开它，弹出一张卡片：

- **八根横杆**，六情 + 思念 + 无聊，每根上面标着数值
- 标题下面一行小字写着「距上次核算多久 · 亮起的情绪」（比如 `5分钟前 · 平静`）
- 最底下两行：思念和无聊的掷骰状态——掷中过就写多久前，没掷中过就写 `—`，夜里就写「夜里停掷」

聊天过程中，**当某种情绪超过 40 分**（并且距上次提醒已过一小时），她会**主动在对话里插一句状态条**，比如：

> 【情绪】悲喜交加（开心 62.1 / 悲伤 71.4）

思念和无聊也有自己的敲门话：

> 思念 60.0，要不要和主人说句话？
> 无聊 63.4，要不要自己做点什么？

---

## 她在做什么

用最简单的话说：**八个数字在后台自己跑，你在前台往文件里写加分，她按时跳动、慢慢消退、偶尔敲门。**

具体来说：

1. **心跳**：每 15 分钟一跳。六情按半衰期自己退（开心退得最快，厌恶退得最慢），思念和无聊按钟点涨
2. **加分**：你在 `room/情绪-加分.txt` 里写一行 `happy+5`，下一跳就吃进去
3. **手动核算**：你在 `room/` 建一个空文件 `情绪-核算.now`，30 秒内她就立刻算一趟（不衰减、马上看结果）
4. **夜里模式**：23:00–07:00 思念涨得慢、无聊不涨、掷骰全停。她也要休息
5. **掷骰敲门**：思念到了 30 分、无聊到了 50 分，每隔 45 分钟掷一次骰子。掷中了就投一句敲门话。到 80 分直接提醒，不掷了
6. **无聊会掉**：他说话无聊打七折，她动手做事（调工具）无聊减半。说话和做事各有各的冷却，互不抢

## 安装

不需要构建、不需要装依赖。

在 DSH 里打开 **设置 → 插件 → 添加插件 → 选择本地目录**，指向 `dsh-mood-changes` 文件夹。

装完不用配任何东西——**第一次打开八个值都是 0，药丸显示「平静」**。不接世界时它只显示状态，不往会话里注入。

---

## 接世界

要让它往会话里投状态条，配一个 `worldId`。在你的 profile 的 `cordis.patch.yml` 里：

```yaml
- id: dsh-mood-changes
  config:
    worldId: lian
```

于是它去 `worlds/<worldId>/` 下读写这些文件：

| 文件 | 谁写 | 干什么的 |
|---|---|---|
| `room/情绪-加分.txt` | 你 | 一行一条加减分，每跳吃一次，吃完清空 |
| `room/情绪-核算.now` | 你 | 建一个空文件 = 立刻算一趟（30 秒内被吃掉） |
| `room/情绪-做事.now` | 你 | 建一个空文件 = 手动补一次「做了点事」，无聊 ×0.5 |
| `life.json` | 别的插件 | 只读里面的 `homeSessionId`，决定往哪个会话投 |
| `mood/state.json` | 插件 | 当前值 + 时间戳，唯一的真源 |
| `mood/mood.log` | 插件 | 每跳一行日志，出事好查 |

## 怎么写加分

写在 `room/情绪-加分.txt` 里，**一行一条**：

```
happy+5
sad+3
anger-2
missing+8
```

支持的英文名：`happy`（开心）、`sad`（悲伤）、`fear`（害怕）、`anger`（生气）、`surprise`（惊讶）、`disgust`（厌恶）、`missing`（思念）。

**`boredom` 不许手写**——无聊只能靠钟点涨、靠说话和做事退。

### 六情的三档

手写加分时按事情的分量选档：

| 档 | 分值 | 叫什么 | 备注 |
|---|---|---|---|
| 一 | 0–5 | 轻轻一下 | 略有波动 |
| 二 | 5–25 | 心里一动 | 波动明显 |
| 三 | 25–30 | 动了根基 | **写这一档会自动触发一次立刻核算** |

### 开心和别人不一样

开心加的分走"积分"——低处涨得快、高处涨得慢。5 分投进去，从 0 起步能推到 14；但到了 80 以后，10 分只推到 82。所以开心天然到不了 100。

其他情绪（悲伤、害怕、生气、惊讶、厌恶）和减分都是实打实的，写多少变多少。

## 主动核算

除了每 15 分钟自己跳一次，你也可以随时按：

- 在 `room/` 里建一个空文件 `情绪-核算.now` → 30 秒内她算一趟，不衰减、立刻看结果
- 往加分文件写一条第三档（25–30） → 写完自动触发

两次主动核算之间至少隔 10 分钟（冷却），防止按太勤。

---

## 夜里 / 白天两段

每天 23:00 进入夜里，07:00 出来。切换时日志里留一行。

| | 白天 | 夜里 |
|---|---|---|
| 思念每跳 | +0.5 | +0.2（×0.4） |
| 无聊每跳 | +4.5 | 不涨 |
| 掷骰 | 开 | 停 |

六情的衰减和亮起不跟这两段走——夜里情绪照样变。

---

## 思念和无聊怎么跑

两条线都没有半衰期，纯靠钟点涨、靠事件掉。

| | 思念 | 无聊 |
|---|---|---|
| 涨速 | 每小时 +2.0（夜里 +0.8） | 每小时 +18（夜里 0） |
| 怎么掉 | **只有主人说话** ×0.8（一小时最多一次） | 有人说话 ×0.7、她做事 ×0.5 |
| 掷骰起点 | 30 分 | 50 分 |
| 直接提醒 | 80 分 | 80 分 |

思念认"主人"的规则（v1.8.1 起）：
- 你在 DSH 对话框里直接输入 → 永远算主人
- QQ 私聊，且对方昵称在 `ownerNames` 配置里 → 主人
- **QQ 群聊里任何人说话（包括你）→ 不扣思念**
- `ownerNames` 不填 = 只有对话框输入算主人，QQ 私聊也不扣

无聊不受影响——有人说话就掉，不管是谁。

无聊掉分两条路各算各的：同一类事件隔一小时才再掉一次，两类之间隔 30 分钟。

## 参数全表

所有参数都在 profile 的 `cordis.patch.yml` 里改，键名跟下面一致。没写的就是默认。

### 节拍

| 键 | 默认 | 干什么的 |
|---|---|---|
| `sweepEveryMinutes` | 15 | 心跳间隔（分钟）。改小退得更勤，改大一次掉更多 |
| `decimals` | 1 | 显示几位小数 |
| `nightStart` / `nightEnd` | 23 / 7 | 夜里时段 |
| `nightMultiplier` | 0.4 | 夜里思念涨幅倍数 |

### 六情

| 键 | 默认 | 干什么的 |
|---|---|---|
| `joyHalfLifeHours` | 5 | 开心退一半要几小时 |
| `sadHalfLifeHours` | 10 | 悲伤 |
| `fearHalfLifeHours` | 12 | 害怕 |
| `angerHalfLifeHours` | 6 | 生气 |
| `surpriseHalfLifeHours` | 2.5 | 惊讶 |
| `disgustHalfLifeHours` | 30 | 厌恶 |
| `lightUpAt` | 40 | 超过这个值算「亮起」 |
| `calmBelow` | 20 | 最高那条不到这个数就显示「平静」 |

### 思念和无聊

| 键 | 默认 | 干什么的 |
|---|---|---|
| `boredomPerHour` | 18 | 无聊每小时涨多少 |
| `boredomDropFactor` | 0.5 | 她做事时无聊乘多少 |
| `boredomTalkDropFactor` | 0.7 | 他说话时无聊乘多少 |
| `boredomSameCooldownMinutes` | 60 | 同类事件冷却 |
| `boredomCrossCooldownMinutes` | 30 | 异类事件冷却 |
| `boredomRollFrom` | 50 | 无聊掷骰起点 |
| `boredomDirectFrom` | 80 | 无聊直接提醒线 |

### 注入

| 键 | 默认 | 干什么的 |
|---|---|---|
| `injectGapMinutes` | 60 | 六情亮起两次注入至少隔多久 |
| `activeCooldownMinutes` | 10 | 两次主动核算至少隔多久 |

## 不做的事

- **不替人写话**。投进去的只有状态、数字和一句问「要不要」的敲门话，没有一句台词是替谁说的
- **关机不补**。插件没在跑的那段整段冻住，不补算、不重置
- **不改别人的文件**。只读 `life.json`，只写自己的 `state.json` 和日志
- **不上插件市场**。只在 GitHub 发布
